# AAV Watermark

Free in-browser photo watermark tool. Photos never leave your device.

- Frame overlay (`watermark.png`) or text/logo watermark, single or tiled
- Drag / pinch / scroll to position the photo under the watermark
- Magic expand: blur, mirror or color fill when zoomed out or changing shape
- Flip, rotate, picture shapes (1:1, 4:5, 9:16, 16:9…)
- Color looks and adjustments
- Batch editing, JPG/PNG/WebP export, iPhone HEIC support

Run locally: `python3 -m http.server` in this folder, then open http://localhost:8000
